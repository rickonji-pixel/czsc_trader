# 588080 Regime条件权重研究设计

日期：2026-09-01  
实验：0901_EX19  
研究对象：`baseline_20260826`

## 1. 目标与边界

检验当前活动基线的固定线性权重是否能通过“单边趋势/箱体震荡”两档市场状态得到更好的风险效率。挑战者允许降低收益率；正式PASS只要求在锁定的2026连续测试窗口同时严格改善最大回撤、卡玛比率和盈亏比。收益率、夏普率、持仓率和交易次数完整报告，但不参与搜索、排名或PASS。

2020—2025全部属于研究数据，2026截至2026-08-28属于本实验锁定测试数据。2026已经被历史研究观察，因此本实验只称其为锁定测试，不宣称全新不可见样本；本实验内部不得利用2026定义regime、选择权重、调整支持度或修改停止条件。

## 3. Regime定义

对后复权日线收盘价计算方向中性的60日路径效率：

```text
ER60[t] = abs(close[t-1] - close[t-61])
          / sum(abs(close[j] - close[j-1]), j=t-60..t-1)
```

每个交易日的标签只允许使用T-1及以前数据。分母为零或历史不足时标记`warmup`，不得用于研究绩效。

分界值是2020-01-01至2025-12-31全部有效ER60观测的经验中位数，只利用ER分布，不使用任何策略收益：

- `ER60 >= median`：`trend`，单边趋势；
- `ER60 < median`：`range`，箱体震荡。

中位数在候选回测前计算一次并冻结。前缀重放必须使用相同的冻结分界，不得在截短数据上重新估计。

## 4. 条件权重模型

现有12个因子沿用`structure`、`trend`、`volume_position`三组。每个regime分别使用两个组乘数：

- 结构组乘数固定为`1.0`，用于消除共同缩放不可识别性；
- 趋势组乘数来自`[0.50, 0.75, 1.00, 1.25, 1.50]`；
- 量价组乘数来自同一网格。

将基线权重按所属组乘以对应乘数，再按绝对值和归一化到L1等于1。组内相对权重、原始符号和因子身份不得改变。`trend`与`range`各有两个自由乘数，共固定生成`5^4 = 625`个候选，包含四个乘数均为1的活动基线等价候选。

当日得分由当日因子值与T-1已知regime对应的权重向量点积得到。`warmup`使用活动基线权重。regime切换不增加确认、滞回或交易规则；其是否引发分数跨阈值由原状态机处理。

## 5. 指标定义

### 5.1 最大回撤

直接使用现有连续资金曲线的最大回撤；数值越接近零越好。

### 5.2 卡玛比率

```text
annualized_return = (ending_equity / initial_cash) ** (252 / trading_days) - 1
calmar = annualized_return / abs(max_drawdown)
```

交易日数使用该窗口实际日线记录数。最大回撤非有限或绝对值不大于`1e-12`时，卡玛无效，候选不得PASS。

### 5.3 盈亏比

只使用完整的买入—卖出闭合交易，按订单实际价格和双边费用计算单笔净收益率：

```text
trade_return = (sell_size * sell_price - sell_fees)
               / (buy_size * buy_price + buy_fees) - 1
win_loss_ratio = mean(positive_trade_returns)
                 / abs(mean(negative_trade_returns))
```

窗口末仍未卖出的持仓不计入盈亏比。若订单不是全仓买入/全仓卖出的交替序列、买卖数量不一致超过`1e-8`相对容差、没有盈利交易或没有亏损交易，则指标无效并拒绝候选。

## 6. 研究集选择

2020用于CZSC和ER预热，正式绩效窗口为2021-01-01至2025-12-31连续资金曲线，同时报告2021—2025五个自然年度。

一个候选进入研究集排名必须同时满足：

1. 连续窗口最大回撤严格优于基线超过`1e-12`；
2. 连续窗口卡玛比率严格高于基线超过`1e-12`；
3. 连续窗口盈亏比严格高于基线超过`1e-12`；
4. 连续窗口至少20笔闭合交易，且不少于基线闭合交易数的50%；
5. 五个年度中至少三个年度的最大回撤与卡玛比率同时严格优于对应基线；
6. 所有指标有限，因果和执行审计通过。

对合格候选计算三项连续指标的相对改善：最大回撤按绝对值下降比例，卡玛和盈亏比按相对上升比例。排名依次使用：三项相对改善的最小值、更高的年度双指标胜出数、更小的权重L1偏移、更小的确定性候选编号。

如果没有候选满足全部研究门槛，实验判为FAIL，不生成冻结挑战者，不读取2026行情。

## 7. 冻结与2026测试

研究胜者必须先写入`frozen_challenger.json`，记录ER分界、两个regime权重、组乘数、基线身份、阈值和状态机身份，并计算SHA-256。冻结文件存在后才允许加载截至2026-08-28的数据。

正式测试为2026年第一个交易日至2026-08-28的连续资金窗口。挑战者PASS必须同时满足：

1. 最大回撤严格优于基线超过`1e-12`；
2. 卡玛比率严格高于基线超过`1e-12`；
3. 盈亏比严格高于基线超过`1e-12`；
4. 至少5笔闭合交易，且不少于基线闭合交易数的50%；
5. 同时存在盈利和亏损闭合交易；
6. 冻结身份、前缀重放、下一交易日开盘执行和费用审计全部PASS。

收益率可以低于基线。夏普率仅客观展示。Q1、H1和M1—M8子窗口只作解释，不增加PASS条件。测试失败后不得回到研究集修改任何参数。
