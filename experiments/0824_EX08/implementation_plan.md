# 实施计划

## 预注册顺序

1. 提交目标、设计、协议和本实施计划。
2. 以TDD增加无可选提前停止、EX08协议验证和纯内存正式编排。
3. 证明EX07仍走SQLite，EX08不创建SQLite且冻结前不打开2026。
4. 提交全部运行代码和测试，记录干净执行提交SHA。
5. 从Trial 0单进程主控、8个只读工作进程执行4096个Trial。
6. 完整导出Trial、排名和批次耗时，复核第一名并冻结。
7. 冻结文件计算SHA-256后执行一次2026验收。
8. 生成执行、结论、产物和实验清单。
9. 运行聚焦测试、完整测试、编译、依赖、diff和全部档案验证。
10. 无论PASS、FAIL或ERROR都提交归档和交接文档。

## 实现边界

- 参数化现有EX07编排，不复制回测、排名、冻结或留出算法。
- 新增EX08专用协议验证和入口。
- `run_study_batches`允许墙钟与停滞条件为`null`，最大Trial数仍强制。
- 研究文档从实验ID生成名称，不硬编码EX07。
- 完成后`study_summary.json`记录4096、存储模式、执行提交、冻结哈希、阶段耗时和2026访问状态。

## 正式命令

```powershell
.\.venv\Scripts\python.exe scripts\run_ex08.py
```

命令必须从干净、已提交的`codex/0824-ex08-inmemory-search`分支执行，实际返回目录是唯一有效运行目录。
