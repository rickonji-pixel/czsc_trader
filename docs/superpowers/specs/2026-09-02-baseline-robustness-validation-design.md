# baseline_20260901 策略稳健性验证设计

日期：2026-09-02  
实验：`0902_EX01`  
研究对象：`baseline_20260901`（EX20候选143）

## 1. 目标与非目标

本实验回答一个问题：当前活动基线的历史优势，在既有搜索空间和冻结数据上有多大概率是搜索偏差、参数尖峰或偶然时序对齐造成的。

实验只做审计，不优化、不调参、不重选候选、不晋升或降级基线，也不更新行情。2026数据不得反馈到策略。结果按证据模块分别报告，不新增一个未经用户授权的综合PASS门槛。

本实验不能证明未来收益或实盘有效性，也不能把已经被历次研究观察过的2026重新称为盲测。

## 2. 冻结身份与数据边界

- 标的：`588080.SH`，资产类型`etf`；
- 活动基线：`baseline_20260901`，策略类型`czsc_regime_weight`，候选编号143；
- 冻结12个因子、归一化、ER60分界、trend/range权重、`0.175/0.025`阈值、状态机、次日开盘执行、初始资金`1,000,000`和单边费率`0.0005`；
- 2020只用于因子与ER预热；搜索审计窗口固定为2021-01-01至2025-12-31；
- 信号错位检验窗口固定为2026-01-01至仓库当前已跟踪的最后完整交易日`2026-09-01`；
- 正式运行前记录基线注册文件、EX20冻结挑战者、协议、源行情清单和关键实现文件SHA-256；正式运行后复核，任何身份漂移均使实验ERROR。

## 3. EX20候选路径重建

按EX20原协议重建固定`5^4 = 625`套regime组乘数组合。每套候选使用同一因子矩阵、ER标签、状态机、执行和费用口径，生成2021—2025完整日收益路径与汇总指标。

重建首先必须复现EX20已存`candidate_results.csv`的候选身份及主要汇总指标。候选143的收益率、最大回撤、卡玛、盈亏比、夏普、持仓率、订单数和闭合交易数须在浮点容差内一致；不一致时停止统计检验并归档ERROR，不得以新结果替换旧档案。

日收益矩阵以压缩NPZ保存，日期和候选身份另存CSV，避免把运行态数据库或超大文本矩阵纳入Git。

## 4. CSCV/PBO搜索偏差检验

将2021—2025共同日收益矩阵按时间顺序分成10个尽量等长的连续区块，枚举全部`C(10,5)=252`个互补训练/验证组合。每个组合在训练半区按年化夏普选择625套中的最优候选，再计算该候选在验证半区的横截面百分位与logit。

PBO定义为验证logit小于零的组合占比。完整保存每个切分的训练胜者、训练/验证夏普、验证名次、百分位和logit。

这是对625套固定网格的标准夏普搜索易错性诊断，不伪称完全复刻EX20的三指标maximin选择器。PBO按连续数值报告；`<0.10`、`0.10—0.50`、`>=0.50`仅作为低、显著、高搜索风险解释带，不作为基线去留门槛。

## 5. Deflated Sharpe Ratio

使用候选143的2021—2025日收益、625套候选夏普的横截面方差、观测数、偏度和超额峰度计算Deflated Sharpe Ratio。试验数固定为625，不把项目中异质实验数量机械相加。

输出观测夏普、估计的随机最大夏普基准、DSR概率和全部公式输入。`0.95`作为常用显著性参考线，仅作解释，不构成新的综合PASS条件。

## 6. 四维参数曲面

完整保留625套候选的四个乘数及收益率、夏普、最大回撤、卡玛、盈亏比、持仓率、订单数和闭合交易数。以候选143为锚，输出：

- 四维曼哈顿距离和欧氏距离；
- 7个一步邻居及所有两步邻居的指标变化；
- 六组两两参数切片，其余两个参数固定为143取值；
- 候选143在各指标中的全局百分位和邻域百分位。

参数稳健性以连续退化曲线、邻域中位数、最差值和分位数呈现，不用事后挑选的阈值把曲面强行二分为高原或尖峰。

## 7. 2026循环移位安慰剂检验

先用冻结基线生成2026-01-01至2026-09-01完整目标仓位序列。保持行情、仓位暴露分布和信号序列内部结构不变，将信号相对市场收益循环移动所有非零合法位移；若共有`N`个交易日，则恰好运行`N-1`个安慰剂，不制造“10000次独立样本”。

每个位移使用与基线相同的次日开盘、费用和独立起始资金回测。主统计量预注册为夏普率；收益率、最大回撤、卡玛、盈亏比、持仓率和订单数只作辅助展示。精确经验P值定义为：

```text
p = (1 + placebo中夏普率不低于真实值的数量) / (1 + placebo数量)
```

同时报告真实夏普的经验分位数。由于循环移位依赖弱平稳近似且窗口边界会影响首尾交易，该检验只回答“真实信号与2026收益的对齐是否异常”，不能单独证明Alpha。

## 10. 测试与错误处理

新增的统计函数必须用小型确定性矩阵验证：CSCV切分互补且无泄漏、PBO排名方向正确、DSR输入与边界可复核、循环移位恰好产生`N-1`个唯一序列、距离和邻居识别正确。正式实验只在这些聚焦测试通过后执行。

正式运行若遇基线身份漂移、625候选不完整、EX20复现失败、非有限日收益、日期错位、2026边界变化或档案不完整，写入ERROR证据并停止；不得自动改变方法、数据或策略后重跑。
