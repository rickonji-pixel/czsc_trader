# 0901_EX11 冠军仓位条件下的CZSC风险事件研究目标

## 可证伪假设

EX10唯一幸存风险事件在冠军持仓或空仓状态之一仍保持跨年、影响点和HAC增量有效性，从而明确它更适合作为离场/减仓信息还是入场过滤信息。

## PASS

`target_0`或`target_1`至少一个条件事件通过0901_EX05共同准入，并在本轮4个确认性“候选—端点”假设的BH校正后满足`q <= 0.10`且方向一致。

## 边界

- 唯一父因子固定为EX10幸存的日线BI涨跌幅第1层退出事件。
- 只按当日已知的冠军目标仓位0/1拆分，不使用未来好坏路径作为因子。
- 评价期2021—2025，不读取2026，不搜索策略。
