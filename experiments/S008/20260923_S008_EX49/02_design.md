# S008 EX49 设计

## 已见数据边界

预注册前的`DISCOVERY_ONLY`权限探测已查看Tushare接口、覆盖起止、行数、空值/重复摘要和
`AU.SHF`换月误差；原始试取只保存在`.tmp/`。尚未计算`Au99.99`上市前年度状态、与518880.SH
重叠期收益一致性或本实验裁决。

## 数据与口径

- 长期代理：DFLS `metal.sge_gold_daily / Au99.99`，2002-10-31至2024-12-31；
- 目标载体：DFLS `etf.ohlcv / 518880.SH`日线，只读取2013-07-29至2024-12-31开发池；
- 禁止读取2025-01-01后的密封验证池；
- 上市前完整年度固定为2003至2012年；
- 年收益按相邻自然年年末收盘价计算；年度最大回撤在该自然年内计算；
- 上涨年度：年收益不低于10%；收缩年度：年收益不高于-10%；冲击年度：年度最大回撤不高于-15%。

## 机器裁决

依次执行数据门、代理一致性门和样本增量门：

1. 数据门要求代理精确覆盖、至少5,390行、主价格字段完整且无重复；
2. 一致性门要求至少2,700个重叠日收益，日收益Pearson不低于0.90、Spearman不低于0.85，
   20日收益Pearson不低于0.95；
3. 样本增量门要求至少8个上市前完整年度、至少3个上涨年度，以及至少1个收缩或冲击年度。

三门全部通过才裁决`PROCEED_TO_PRE_ETF_REGIME_MECHANISM_AUDIT`。这些年度桶用于降低日频自相关
造成的虚假样本量，但不宣称年度之间统计独立，也不构成Alpha证据。
