2. 以测试驱动实现下行波动、滞后压力阈值、27项候选路径及变仓事件。
3. 实现严格协议校验、选择期硬约束与稳定排序。
4. 只读取截至2025的数据完成候选选择；无合格候选则FAIL并停止。
5. 合格候选落盘并哈希后才加载2026，执行2026FULL主判定及三个诊断窗口。
6. 如实归档PASS、FAIL或ERROR，更新研究交接并完成全套验证。
