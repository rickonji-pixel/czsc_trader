# 实施计划

1. 先提交目标、设计、可机读协议和工程计划，形成结果产生前的Git预注册。
2. 用测试驱动新增动态仓位状态机及 `Entry/Reduce/Increase/Exit` 事件。
3. 扩展通用订单溯源和因果审计，精确验证持仓内变仓。
4. 注册独立研究处理器，只读取截至2025年的数据完成可见诊断和挑战者冻结。
5. 冻结完成后才读取2026，按原三个窗口和收益率单目标规则验收。
6. 生成PASS、FAIL或ERROR档案，更新研究交接，完成验证后提交推送。
