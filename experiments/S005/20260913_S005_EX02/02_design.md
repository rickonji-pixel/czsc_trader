# S005 EX02 设计

四个机制分别检验：

1. 隔夜正向信息是否在开盘后被价格和成交量共同确认；
2. 588080 是否在早盘形成相对 510500 的显著领涨；
3. 早盘冲高后的浅回撤是否被承接并在午后重新启动；
4. 日线低波动压缩是否以放量、收近高位和突破共同结束。

阈值、决策时点和密度门均冻结在 `artifacts/protocol.json`。脚本只能读取决策时点及以前的
价格和成交量；不计算任何事件后的收益。相邻事件执行一交易日冷却，避免把连续行情切碎为
虚假的独立样本。只有滚动 60 交易日事件中位数不少于 7 且 P10 不少于 3 的机制，才可进入
下一轮固定收益证伪。
