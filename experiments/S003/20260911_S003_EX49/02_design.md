# S003 EX49 冻结设计

- 指数：000852.SH（中证1000）；执行标的：512100.SH
- 区间：2021-01-04 至 2026-09-08；额外读取 2020-12 的权重快照用于首日因果映射
- 成分规则：月度权重快照仅从下一个 512100 交易日起生效
- 资金流：Tushare `moneyflow.net_mf_amount`；按交易日拉取全市场后只保留当日历史成分
- 缺失：不填充；每日按已观测权重重新归一化
- 质量门：权重结构完整；总体成员覆盖率不低于 98%；单日成员覆盖率第10百分位不低于 97%；单日已观测权重第10百分位不低于 97%，最小不低于 90%
- 成本门：首次 API 调用总量不超过 1600；持续维护为每交易日一次资金流、每月一次权重
- 隔离：禁止宽度、事件、收益、参数和候选计算
