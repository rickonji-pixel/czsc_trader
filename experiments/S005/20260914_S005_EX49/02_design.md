# S005 EX49 设计

使用CZSC 1.0.1注册表中全部`kline`类信号，每个函数只采用一个原生默认参数配置，分别在
30分钟、日线和周线生成信号。30分钟取每日15:00已经完成的快照，周线只向后对齐，所有
观察截止于2026-09-02。

每个信号的主状态独立展开；只有从非该状态切换为该状态时才记一次事件，连续维持不重复计数。
本轮保存完整状态，但不赋予多空方向，也不读取状态之后的588080行情或收益。

技术准入规则：

1. 信号观察覆盖率不低于80%；
2. 主状态不是“其他、任意、中性”等无明确语义占位状态；
3. 状态激活比例在2%至98%之间；
4. 至少10次独立切换，覆盖不少于4个自然年；
5. 日级激活序列完全重复时，只保留确定性排序第一项作为规范状态，其余保留审计但标记重复。

中频机会池须进一步达到S005固定证据速度门：滚动60交易日独立切换次数中位数不少于7、
P10不少于3。没有达到频率门、但通过技术准入的状态只进入确认或风险因子人工复核池，不能
独立形成策略。S001使用过的函数只做重合标记，不复用其权重、聚合公式或状态机。
