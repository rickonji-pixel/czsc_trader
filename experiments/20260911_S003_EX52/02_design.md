# S003 EX52 冻结设计

- 两个市场使用同一个未经调整的资金流宽度机制和执行规则
- 月度区块 Bootstrap：两市场共同按同一组连续 3 个月区块重采样 10,000 次，保留时间自相关和市场相关性
- 通过下界：两市场等权的单笔压力收益均值 90% 置信区间下界大于 0；两市场同时为正的概率不低于 80%
- 参数平原：分别在 q75、q80、q85 阈值重算；六个“市场×阈值”压力收益均值都必须大于 0
- 证据标签：综合门通过且 EX47 DSR 仍不利时为 `MIXED`；综合门失败为 `ADVERSE`
- `MIXED` 只允许进入候选定义、PK、体检流程，不自动创建或冻结候选
