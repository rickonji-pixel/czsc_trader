# 研究设计

- 冠军：注册表活动版本`baseline_20260826`。
- 数据：2020只预热；诊断信号限于2021-01-01至2023-12-31。
- 趋势破坏代表态：60日先前高点回撤不低于-10%，且收盘低于20日均线。
- 下跌持续代表态：10日内至少7个负收益日，且收盘低于20日均线。
- 日内压力代表态：收盘位置不高于0.25、下跌30分钟K线成交量占比不低于0.70，且收盘低于20日均线。
- 只在冠军持仓日统计；T日状态的5/10日结果从T后下一开盘开始，使用其后开盘收益和区间最低价最大不利波动。
- 输出事件数、均值、中位数、损失尾部率、逐年方向、状态重叠和单事件集中度。
- 不读取2024、2025或2026。
