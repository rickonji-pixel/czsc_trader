# S005 EX04 设计

- 信号：EX03冻结的 `RELATIVE_FLOW_Q80`，不改阈值；
- 执行：信号次一交易日开盘买入、当日收盘卖出；
- 成本：基准单边1.2bp，压力单边6bp；
- 随机对照：保持逐年事件数量，以年度内循环位移生成1000组对照；
- 质量门：压力收益为正、盈亏比大于1、至少4个正收益年、最近252日为正、随机分位不低于90%；
- 目标门：代理账户年化收益不低于EX01冻结值、最大回撤不深于15%；
- 本轮只检验一条收益路径；失败即停止该机制族，不改持有期补救。

本实验不生成候选，不修改SM或PTE。即使全部通过，仍需独立完成机制归因和正式TDR复算。
