# S005 EX71 设计

## 输入

输入固定为EX49的`state_eligibility.csv.gz`。该文件包含成功生成的2092个主状态，以及覆盖、语义、
激活比例、切换次数、覆盖年份、精确重复关系和滚动60日频率。运行前必须校验EX49归档和输入哈希。

## 新技术口径

状态按以下顺序归类：

1. `DATA_COVERAGE_FAIL`：覆盖不满足EX49既定80%数据质量门；
2. `DUPLICATE_ALIAS`：日级激活序列与规范状态完全相同，保留映射但不重复审计；
3. `SEMANTIC_CONTEXT_ONLY`：主状态属于“其他、任意、中性、零轴附近”等方向语义占位，仅作上下文；
4. `INFORMATION_AUDIT_UNIVERSE`：进入后续信息价值审计全集。

激活比例、独立切换次数、覆盖年份、滚动60日中位数及P10全部保留为描述字段，不参与上述准入。
旧口径因这些条件被排除、但新口径恢复的状态必须逐项标记恢复原因。

## 边界

- 本轮不读取任何状态之后的行情或收益；
- 不判定多空方向、Alpha、职责或组合价值；
- 不执行完整策略`7/3`频率门；
- 不创建候选，不修改SM或PTE；
- 下一轮必须在完整新全集上预注册信息审计协议，所有读取收益的方向与期限均计入搜索账本。
