# S008 EX53 实验设计

## 数据与因果对齐

- 目标代理：DFLS `metal.sge_gold_daily / Au99.99`，2002-10-31至2024-12-31；
- ETF桥接：DFLS `etf.ohlcv / 518880.SH`，仅使用2013-07-29至2024-12-31开发池；
- 新输入：EX52通过的伦敦金、伦敦银、VIX、SPX、RUT和IXIC；
- 发现段固定为2003-01-02至2012-12-31，确认段固定为2013-07-29至2024-12-31；
- 所有全球输入按源日期严格早于中国目标交易日做向后对齐，禁止同日值进入中国收盘决策；
- 预测周期固定为20、60和120个交易日，60日为主周期；标签退出日不得越过所属分段。

## 冻结信息路径

14项特征的方向由金融机制预先确定，不按结果翻转。核心避险需求包括金银相对强弱、金银比趋势
以及黄金相对标普强弱；风险确认包括VIX水平/变化/短长比、SPX/RUT/IXIC下跌与波动、以及小盘
和成长相对标普走弱。

路径必须在上市前SGE、上市后SGE和上市后ETF三处定向IC均不低于0.03，三个周期至少两个为正，
确认期至少6个年度IC为正，120日块Bootstrap正向概率不低于0.75，ETF最高与最低五分位收益差
为正。HAC显著性和全局FDR用于证据分级。

## 裁决

60日主周期至少需要一条`SAFE_HAVEN_DEMAND`路径、一条`GLOBAL_RISK_CONFIRMATION`路径，并且至少
一条支持路径取得单侧HAC名义显著，才裁决
`PROCEED_TO_GLOBAL_SAFE_HAVEN_PROTOTYPE_PREREGISTRATION`。否则分别停止于核心需求、风险确认或
统计支持不足。通过只表示有资格设计原型，不代表策略可交易或达到用户收益与回撤硬门。
