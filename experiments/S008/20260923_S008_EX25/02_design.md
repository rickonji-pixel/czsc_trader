# S008 EX25 实验设计

1. 三套原型分别建立独立、固定种子的 Optuna NSGA-II 多目标 study，每套恰好尝试 1,500 个
   trial，总预算 4,500；不早停、不剪枝、不共享搜索历史，也不依据中间结果改变空间或预算。
2. 参数边界与约束逐项继承 EX19；连续权重先在冻结边界内采样，再按各自权重族归一化。违反
   阈值顺序等显式约束的路径仍进入 trial 账本，不静默丢弃。
3. 搜索目标为主成本口径下最大化年化收益、最小化最大回撤幅度。机器合格条件只有用户确认的
   两项硬门：年化收益不低于同口径 BuyHold 的 1.5 倍，且最大回撤幅度小于 BuyHold。
4. 策略与 BuyHold 使用相同标的、评价起止、初始资金、T+1 开盘执行和成本。统一评价起点是
   开发池中 13 个定向归一化组件首次全部有限值的交易日；该边界只由输入完备性确定。
5. 主成本为单边 10bp；单边 30bp 仅形成压力诊断。卡玛、盈亏比、交易频率、分段一致性、
   PBO、DSR、Bootstrap 与参数邻域均不参与本阶段机器硬门。
6. trial 账本保留每次尝试的参数、约束状态、Optuna 状态、异常、目标值、主/压力执行指标、
   BuyHold 对照、硬门判断以及代码、数据、协议和依赖身份。执行异常立即终止本实验并由后继
   实验处理；不得以补跑或跳过改变本实验。
7. 本实验不调用 DFLS 读取真实行情、不计算真实收益、不创建 Optuna study、不选择胜者、不读
   封存验证池、不创建候选，也不修改平台、治理区或 PTE。
