# S006 EX07 设计

EX06对事件因子预注册了10个确认期观察的可识别门槛，但统一HAC计算至少要求20个观察。新闻事件路径只有13个确认期观察，因而出现`identifiable=true`而HAC统计为空的契约矛盾。

本轮不读取新收益、不改变任何数值，只执行以下确定性修订：

1. 对`EVENT_FACTOR`且确认期观察少于20条的路径，将`identifiable`改为`false`；
2. 将其证据标签改为`UNIDENTIFIABLE`；
3. 其余字段和2,040条路径全部保持原样；
4. 校验7条全局FDR支持路径及后续裁决不变；
5. 生成带来源哈希的修订总账，后续实验只能读取该总账。
