# S005 EX68 设计

## 冻结规则

1. 因子与信号组件先检查数据、因果、技术质量、信息价值、稳健性和互补性；频率只披露。
2. 组件可以是低频环境、确认或风险信息，不需要独立满足最终策略交易频率。
3. 只有完整定义进场、退出、持仓和执行规则的策略，才检查滚动60日闭合交易`7/3`门。
4. 历史实验不回写；纠偏通过新增审计档案表达。

## 对历史证据的处理

- EX65与EX67的数据、连续因子和频率统计继续有效；
- 两者只能得出“不适合独立承担S005中频触发”的结论；
- `STOP_*_ON_DENSITY`不得解释为对应信息族或因子无预测价值；
- 下一轮允许复用连续因子评估信息价值，读取收益时必须计入搜索审计。
