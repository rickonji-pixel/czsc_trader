# 研究设计

## 固定因子集合

使用冠军当前全部12个底层信号：结构类6个、趋势类4个、量价类2个。分类信号到`[-1, 0, 1]`的归一化规则并入因子定义，不再作为独立策略层。因子名称、频率、参数和归一化规则全部冻结。

## 等价四层模型

冠军三组权重为`0.3、0.3、0.4`，组内使用算术平均。展开后：

- 6个结构信号各`0.3 / 6 = 0.05`；
- 4个趋势信号各`0.3 / 4 = 0.075`；
- 2个量价信号各`0.4 / 2 = 0.20`。

12项权重绝对值和为1，固定计分公式为因子矩阵与权重向量的点积。正式搜索前必须验证展开得分与冠军得分最大绝对误差不超过`1e-12`，目标仓位逐日完全相同。

## 仅优化权重和阈值

权重优化以等价权重为起点，采用确定性坐标搜索。每次只对一个固定因子尝试`+step`、`-step`，可选时尝试翻转符号；随后按L1范数归一化。任何权重绝对值小于`0.005`的候选均无效，确保12个因子始终存在且非零。

候选配置：

- 步长：`0.025、0.05`；
- 坐标轮数：`1、2`；
- 允许符号翻转：`false、true`；
- 入场阈值：`0.10、0.15、0.20`；
- 离场阈值：`-0.05、0.00、0.05`，且小于入场阈值。

共72种算法配置。状态机固定为冠军的入场确认1日、最短持仓3日、离场确认1日、无额外门控。

为避免把阈值差异混入权重拟合，坐标搜索统一使用冠军阈值`0.15 / 0.00`；每个扩展验证窗口再将拟合权重与9组预注册阈值组合评估。最终按胜出配置的坐标参数在2021—2025重拟合权重，并应用该配置的冻结阈值。

## 选择协议

使用扩展窗口：训练2021—2022验证2023，训练2021—2023验证2024，训练2021—2024验证2025。坐标搜索直接优化训练年度组合相对冠军的收益率和夏普率，不使用未来收益预测代理。

训练目标和配置排序均依次采用：双指标获胜窗口数、最差收益增量、最差夏普增量、平均收益增量、平均夏普增量、更小权重偏移、确定性编号。选定算法配置后，在2021—2025重新拟合一次并冻结；2026结果不得反向改变配置、权重或阈值。

## 产物与结论

输出等价证明、候选结果、12项冻结权重、冻结挑战者、选择指标、留出指标、订单、四份研究文档和manifest。无论PASS或FAIL均保留完整证据，冠军只有在三个留出窗口全部PASS时才允许后续晋升。
