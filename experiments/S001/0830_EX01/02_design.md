# 研究设计

## 1. 冠军与仓位职责

冠军固定为注册表活动版本 `baseline_20260826`，规范SHA-256为 `fc22ca5a973f77faf528cdb3efba4900163e18fe0c08cf79234d79ef22f5c822`，源冻结文件为 `experiments/0824_EX04/artifacts/frozen_challenger.json`。基线二元路径继续独占进出场职责；风险模块只把基线持仓乘以1或压力仓位，不能在基线空仓时建立仓位。

## 2. 下行波动

日对数收益为 `r_t`。回看周期L的下行波动率为最近L个已完成收益中 `min(r, 0)` 平方均值的年化平方根。T日压力阈值只使用T-1及以前最近252个有效下行波动值的Q分位数；当前值严格超过阈值时进入压力状态。历史不足时保持正常状态。

固定候选为：

- `L = 10、20、40`；
- `Q = 0.70、0.80、0.90`；
- 压力仓位 `P = 0.25、0.50、0.75`。

共27项，不增加其他隐含参数。正常状态为满仓，压力状态为P；目标变化在下一交易日开盘执行并支付手续费。

## 3. 选择与冻结

2020只作预热。2021年第一个交易日至2025年最后一个交易日为完整选择区间；2021—2025五个自然年度分别独立注资作稳定性诊断。

合格候选必须同时满足：完整区间费后收益不低于冠军，且最大回撤数值严格高于冠军。合格候选依次按完整区间回撤改善、最差年度收益增量、交易次数、候选ID排序。没有合格候选则归档FAIL且`holdout_accessed=false`。

唯一获选候选写入冻结文件并计算SHA-256后，正式运行器才允许加载2026。

## 4. 2026最终结果

主窗口 `2026FULL` 从2026年第一个实际交易日至2026-08-28。挑战者费后收益不低于冠军并且最大回撤严格改善才为PASS。原 `2026Q1、2026H1、2026M1-M8` 只展示阶段性指标，不参与本轮主判定，也不改写既有冠军挑战协议。

## 5. 审计与状态

每笔入场、退出、减仓和恢复订单都必须连接唯一事件；信号日严格早于下一交易日执行日；滚动分位数排除当前值；事件仓位与目标路径一致；vectorbt与独立资金账本逐日一致。协议漂移、身份错误、数据泄漏、账本或审计失败归档ERROR，不包装为策略FAIL。
