# S005 EX59 设计

## 金融假设

持续性需求应同时留下四类痕迹：多数成分共同上涨、成分资金流广泛转正、ETF一级市场份额增加，
以及二级市场价格没有严重偏离净值。单一痕迹可能只是追涨、机械申赎或暂时错价；四类信息协同
出现时，才代表需求由成分股到ETF申赎链路一致传导。

## 固定计分

1. 成分参与度：成分权重涨跌宽度与其5日均值的历史百分位均值。
2. 成分资金：正资金流成分权重宽度的历史百分位。
3. 一级市场：ETF份额变化的历史百分位。
4. 定价效率：ETF折溢价绝对值历史百分位的反向值。

每项只与此前120个交易日比较，四组等权。组合分数再与此前120日比较，Q50、Q60、Q70仅用于
无收益密度校准；同一分位事件冷却3个交易日。选择通过滚动60日中位数7、P10为3的最高分位，
才允许下一轮冻结唯一收益路径。

本轮不得读取后续收益、调整因子方向或权重、生成候选、修改SM或PTE。
