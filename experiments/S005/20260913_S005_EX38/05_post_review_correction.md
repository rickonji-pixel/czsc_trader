# S005 EX38 评审纠正

用户评审指出：新闻正文到结构化事件的语义筛选器是Codex，不需要先由确定性程序证明自己能够替代Codex。

EX38的数值结果和原始裁决继续作为失败证据保留，但其适用范围仅限于EX37程序：该程序不能作为排除文章的硬门，不能用“未命中”阻止Codex阅读。它可以用于阅读排序和提示候选，不能减少必须完成语义审核的新闻全集。

修正后的工作流是：完整回填并本地缓存新浪财经原文；机械去重后，由Codex分批阅读标题和正文，判断相关性、抽取结构化事件与方向；每篇文章都落库审核状态、证据摘录和理由。程序负责数据获取、去重、任务编排、完整性校验和缓存，不负责最终语义淘汰。

后续裁决更新为`PROGRAM_PREFILTER_REJECTED_CODEX_FULL_REVIEW_APPROVED`。EX38没有读取事件后行情或收益，因此该纠正不引入收益污染。
