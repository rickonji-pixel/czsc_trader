# 588080 回测交互式日线图设计

## 目标

在每次研究输出目录中，为三个独立回测周期分别生成一份可离线打开的 Plotly HTML：

- `chart_2026Q1.html`
- `chart_2026H1.html`
- `chart_2026_01_08.html`

图表用于解释既有回测，不改变因子、仓位、订单、收益或参数选择。

## 数据边界

图表只读取 `data/raw` 中已验证的日线数据、研究流程已经生成的因子矩阵，以及每个周期的实际订单。CZSC 结构计算可以使用周期开始前的数据预热，但不得使用周期结束后的K线。因子信号和实际交易点直接采用回测使用的日期与值，避免重新推导造成不一致。

## 图层

每份HTML包含两个同步缩放的面板。

主面板包括：

1. 回测周期内的日K线。
2. CZSC 1.0.1 根据截至周期末日线生成的已确认笔，以折线连接笔端点。
3. CZSC `cxt_five_bi_V230619` 与 `cxt_seven_bi_V230620` 历史信号中包含“底背驰”或“顶背驰”的触发点。信号使用逐日历史生成接口，背驰只作为解释图层，不进入策略。
4. 基础多因子仓位 `base_target_position` 从0变1或从1变0的信号点，分别标记“因子入场”和“因子离场”。
5. 对应周期 `orders_<周期>.csv` 中由 vectorbt 产生的实际 Buy/Sell 成交点，标记成交日期、价格、份额和手续费。

副面板包括：

- `structure`
- `trend`
- `volume_position`
- `factor_score`

所有图层可通过图例独立开关，悬停显示日期与详细值，横轴范围同步。

## 结构语义

“笔”来自CZSC对象的 `bi_list`，并使用周期结束日之前的全部日线构造。图中不显示线段。背驰采用CZSC官方五笔/七笔形态信号，避免在策略项目内自定义背驰算法。

笔是周期结束时已经确认的解释性结构；策略交易仍只由此前已经审计过的逐日因子信号驱动。图表不得把笔或背驰结果反向写入回测仓位。

## 输出与复现

HTML嵌入 Plotly JavaScript，双击即可离线打开。`manifest.json` 增加图表文件列表、绘图库版本、背驰信号名称和图表数据截止说明。`report.md` 增加三张图的文件索引。

若某周期没有背驰、因子切换或交易点，仍生成图表，并保留对应空图层的说明。CZSC结构或HTML生成失败时研究任务应失败，不允许静默缺失图表。

## 测试与验收

自动化测试覆盖：

1. 每个周期图表只含该周期K线，不含周期结束后的日期。
2. 笔端点来自CZSC输出，且位于可用K线范围内。
3. 因子信号日期对应 `base_target_position` 的真实变化。
4. 交易点与独立周期订单逐笔一致。
5. 三份HTML存在、可解析，并包含K线、笔、背驰、因子信号和交易图层标识。
6. 原有无前视审计和三个收益目标保持通过。

完成后运行完整测试，并生成当天的新修订输出目录进行人工HTML渲染检查。
