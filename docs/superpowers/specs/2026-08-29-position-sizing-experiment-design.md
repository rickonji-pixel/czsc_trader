# 588080入场定仓实验设计

## 目标

检验当前活动正式基线 `baseline_20260826` 的冻结综合分数，除了决定是否入场外，能否在入场当日区分半仓和满仓，从而在不改变因子、权重、进出场时点和冠军挑战规则的前提下提高588080单标的费后收益。

本轮正式实验编号为 `0829_EX01`。它是单标的仓位架构挑战，不修改活动基线；只有实验PASS且另行作出晋级决定后，才允许讨论基线变更。

## 冻结边界

- 冠军身份只从 `configs/rule_baselines/registry.json` 解析，固定为 `baseline_20260826`。
- 12个CZSC因子、因子归一化、冻结权重、入场阈值 `0.175`、离场阈值 `0.025`、确认日、最短持有期、退出确认日和次日开盘执行全部保持不变。
- 挑战者只增加一个满仓阈值，候选集合固定为 `0.200、0.225、0.250`。
- 综合分数低于 `0.175` 时不入场；达到 `0.175` 但低于候选满仓阈值时以 `0.5` 入场；达到满仓阈值时以 `1.0` 入场。
- 仓位只在入场信号日确定。持有期间即使分数变化也不在半仓和满仓之间调整；原退出信号触发时一次性清仓。
- 半仓表示执行日开盘时用执行前组合资产的50%买入，买入后持股数量保持不变，不做每日目标比例再平衡。
- 手续费固定为单边 `0.0005`，初始资金固定为 `1,000,000`。

## 选择和PASS规则

沿用 `0824_EX04` 的收益率单目标冠军挑战协议：

1. 选择样本截止 `2025-12-31`。
2. 验证窗口固定为 `2022H1` 至 `2025H2` 八个半年。
3. 三个候选按以下顺序排序：收益严格高于冠军的窗口数、最差窗口收益增量、收益增量中位数、平均收益增量、候选ID字典序。
4. 夏普、最大回撤、持仓率和交易次数只完整展示，不参与拟合、排序或PASS。
5. 选定候选写入冻结文件并计算SHA-256后，才允许加载2026数据。
6. 正式窗口保持 `2026Q1`、`2026H1`、`2026M1-M8`，其中最后一个窗口截止 `2026-08-21`。
7. 挑战者在三个窗口的费后收益率都必须严格高于冠军才为PASS，否则为FAIL。

2026结果已经被项目观察。本轮仍按原协议执行以保持可比性，但不把这些窗口重新描述成未见独立证据，也不依据结果进行二次调参。

## 软件边界

新增纯函数负责“入场定仓、持有不调仓”的状态路径和因果事件。通用回测层扩展为接受闭区间 `[0, 1]` 的目标仓位，并只在目标状态改变时向 vectorbt 发出目标比例订单，防止半仓被每日再平衡。独立权益账本必须逐笔复算同一变仓过程，并与 vectorbt 权益逐日一致。

因果审计扩展为接受 `0、0.5、1`：入场是 `0 -> 正仓位`，退出是 `正仓位 -> 0`，每笔订单仍必须连接唯一信号事件并在下一交易日执行。既有二元基线行为必须保持不变。

新增研究处理器 `entry_fixed_position_sizing`，由统一 `experiment run` 入口执行。正式运行必须验证协议常量、冠军哈希和源冻结文件身份。成功与否都写入Git跟踪实验档案；运行异常则写入 `ERROR` 档案和错误摘要，不伪造PASS或FAIL。
