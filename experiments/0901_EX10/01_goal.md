# 0901_EX10 CZSC路线多重比较审计目标

## 可证伪假设

0901_EX06—EX09的形式准入候选中，至少一个在同时校正全部基础合格因子和两个20日端点后，仍提供冠军12因子及目标仓位之外的统计增量。

## PASS

至少一个原形式准入端点满足全局Benjamini–Hochberg `q <= 0.10`，且HAC回归系数方向与原条件效应一致。PASS只保留后续研究资格，不表示策略胜出。

## 边界

- 输入档案固定为0901_EX06—EX09。
- 回归控制项固定为冠军目标仓位与12个冻结因子；Newey–West最大滞后固定20日。
- 全部家族和收益、最大回撤两个端点一起校正。
- 不读取2026，不调整既有因子定义或形式PASS结果。
