# S005 EX58 设计

## 数据复用

- ER60和五个首小时因子从冻结研究池重新确定性计算。
- 成分涨跌宽度、成分资金流宽度复用EX18时点成分面板。
- ETF份额变化和净值折溢价复用EX26。
- 盈利加速度宽度复用EX44；结构化新闻事件复用EX40。

统一长表同时保存信息所属日期、最早可用日期与时钟。连续数值、稀疏事件和非数值事件保持各自
语义，不用零填充伪造共同覆盖。因子是否独立于588080自身OHLCV单独标记。

## 门禁

1. 13个项目因子必须全部进入盘点；无法形成数值的因子也须以事件记录入账。
2. 已观测数值必须有限，日期不得超过开发池截止。
3. 定义、实现或可用时间不一致时明确失败，不能用“成功生成文件”替代契约正确。
4. 本轮禁止读取后续收益、生成信号、创建候选、修改SM或PTE。
