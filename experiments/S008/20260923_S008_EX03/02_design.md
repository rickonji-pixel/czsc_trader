# S008 EX03 实验设计

## 证据边界

- 数据：`research/S008/materials.json`绑定的518880.SH研究数据与不复权执行数据；
- 只读取2013-07-29至2024-12-31开发池文件，禁止打开2025—2026封存验证文件；
- 本实验由`DISCOVERY_ONLY`开放探索触发，同一开发池已经用于形成原型和参数范围，因此结果只属于
  内部机制稳健性证据，不具有独立样本外含义；
- T日收盘形成目标仓位，T+1开盘成交，随后按相邻开盘价计量持仓收益；
- 单边10bp为参考诊断，单边30bp为成本压力诊断，两者都不是候选硬门。

## 冻结原型空间

1. Donchian：进入窗口`[60, 90, 120, 150, 180, 210, 240]`，退出窗口
   `[20, 40, 60, 80, 120]`，且退出窗口小于进入窗口；
2. 双均线：快线`[20, 40, 60, 90]`，慢线`[120, 180, 240]`；
3. 时间序列动量：回看`[60, 120, 180, 240, 360]`；
4. BuyHold只作为对手，不参与参数平台判定；
5. 效率门控、ETF份额和tsfresh特征不进入本实验，因为开放探索没有观察到稳定增量。

## 观察窗口与指标

每一配置完整保留trial ledger，并分别报告完整开发池、2013—2017、2018—2021、2022—2024三个
内部时期的年化、最大回撤、卡玛、入场次数、暴露、换手、最差年度和正收益年度集中度。

单一配置取得机制资格须同时满足：

1. 10bp下完整开发池卡玛高于同口径BuyHold且最大回撤更小；
2. 10bp下三个内部时期年化收益均为正；
3. 30bp下完整开发池年化收益仍为正；
4. 完整开发池至少6次入场；
5. 收益最高两个正收益年度占全部正年度收益不超过75%。

同一原型族中，合格配置按参数网格相邻关系组成的最大连通区域不少于3个配置，证据标签为
`FAVORABLE`；存在合格配置但最大连通区域不足3个，标签为`MIXED`；没有合格配置，标签为
`ADVERSE`。裁决只决定是否值得进入策略原型预注册，不能产生候选或证明Alpha。
