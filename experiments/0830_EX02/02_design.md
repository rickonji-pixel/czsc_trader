# 研究设计

## 1. 冠军与风险模块

冠军只从注册表解析为 `baseline_20260826`。冠军二元仓位独占进出场；风险模块仅在冠军持仓时将目标乘以1或压力仓位，不能覆盖冠军空仓。

## 2. 候选与因果计算

下行波动率是最近L个日对数收益中 `min(r,0)` 平方均值的年化平方根。T日阈值只使用T-1及以前最近252个有效下行波动值的Q分位数；当前值严格超过阈值时采用P，否则满仓。固定27项候选不增加其他参数。

日线输入在计算前把`dt`列规范为唯一递增DatetimeIndex。这是相对EX01的唯一实现修复，不改变任何数值规则。

## 3. 选择、冻结和2026

2021年第一个交易日至2025年最后一个交易日用于完整选择，2021—2025五个年度独立注资作稳定性诊断。合格候选必须完整期收益不低于冠军且最大回撤严格改善；依次按回撤改善、最差年度收益增量、交易次数和候选ID排序。无合格候选则FAIL且不访问2026。

唯一获选候选落盘并计算SHA-256后才加载2026。2026FULL收益不低于冠军且最大回撤严格改善才PASS；三个既有2026窗口只作诊断。

## 4. 审计与状态

滚动阈值排除当前值；所有订单连接唯一事件并于下一交易日开盘执行；事件仓位、风险输入、vectorbt与独立账本全部一致。正常完成写PASS或FAIL，任何异常写ERROR并保留真实`holdout_accessed`。
