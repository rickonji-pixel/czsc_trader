# S007 EX42 设计

- 基线为 `S007-v1` 在 2021-01-05 至 2026-09-02 研究数据上的完整 SRT 信号与 TXE 账户回放，单边成本 10bp；
- 固定检查点为买入成交当日收盘。仅当成本后盯市净收益小于等于 0 且基础策略原本继续持有时，覆盖层把下一交易日目标改为空仓；
- 提前退出后，在原 `S007-v1` 持仓周期恢复为空仓前保持封锁，防止同一基础周期重复进出；基础策略原有退出保持不变；
- 覆盖层目标序列是实验内的研究反事实，使用冻结执行契约交给 TXE 生成订单、成交、账户和交易账本，不声明为 `S007-v1` 自身输出；
- 收益与风险比较使用同一数据、整手、现金、涨跌停和成本语义；目标序列必须通过 SE 账本审计；
- “不交易”诊断单列闭合交易数、年度零交易数、滚动 60 日闭合交易中位数/P10/零交易窗口、账户持仓暴露、1 日交易占比、成交金额和成本。它们是本轮观察项，不自动成为研究硬门槛。
