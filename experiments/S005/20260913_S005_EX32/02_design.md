# S005 EX32 设计

金融假设一：ETF收盘价明显低于当日净值，表示二级市场卖压短暂超过一级市场套利的吸收能力，折价可能在数日内修复。竞争解释是，折价来自净值估算滞后或真实的持续卖压，不具备可交易的回归价值。

金融假设二：ETF收盘价明显高于当日净值，可能代表尚未被一级市场完全满足的增量需求，其价格动量可能延续。竞争解释是，溢价只是短暂的套利错价，后续只会收敛。

以`close / nav - 1`定义折溢价率，使用当日以前120个可用观测的Q50/Q60/Q70定义强度。`DISCOUNT_REVERSION`要求折溢价率小于0并低于对应下分位；`PREMIUM_DEMAND`要求数值大于0并高于对应上分位。同族同参数冷却3个交易日，密度门为滚动60日中位数至少7笔、P10至少3笔。

后续唯一收益路径按“折价修复优先，同族选择通过密度门的最高分位”冻结；折价族无通过项时，才允许溢价需求族获得检验资格。T日数据按Tushare文档在T+1日08:30左右发布，事件只能从T+1日09:36起使用。
