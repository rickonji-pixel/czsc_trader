# S001 EX02 设计

1. 固定复用 `20260913_S001_EX01` 的策略版本、数据截止和前三大回撤区间。
2. 通过 TDR Backtest v2 重放 S001-v2，保留决策、订单、账户和交易账本。
3. 使用两种互补口径归因：
   - 入场状态：每笔闭合交易按买入决策的 `regime` 分类；
   - 逐日状态：回撤区间内每日账户收益按当日信号的 `regime` 分类。
4. 若某个状态贡献前三大回撤区间至少 60% 的负收益日损失，则下一轮优先研究该状态；否则按混合来源处理。

逐日状态只解释损失发生时的市场环境，入场状态只解释交易开始时的市场环境；二者均不单独证明因果。
