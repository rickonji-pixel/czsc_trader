# 实施计划

1. 先提交本目标、设计和可机读协议，形成结果产生前的Git预注册。
2. 以测试驱动方式扩展分数到入场仓位的映射、分数仓位回测和因果审计。
3. 注册独立研究处理器，先验证协议与冠军身份，只读取截至2025年的选择数据。
4. 评估三个固定候选，按原收益率规则选优并冻结候选文件。
5. 冻结完成后才读取2026并执行原三个冠军挑战窗口。
6. 生成PASS、FAIL或ERROR档案，更新交接文档，运行全套验证后提交推送。

详细开发步骤固定在 `docs/superpowers/plans/2026-08-29-position-sizing-experiment.md`。
