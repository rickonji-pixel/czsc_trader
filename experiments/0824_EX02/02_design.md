# 研究设计

## 1. 策略架构边界

当前冠军按以下路径产生仓位：

```text
CZSC底层分类信号
  -> 通用语义映射（-1 / 0 / 1）
  -> structure / trend / volume_position 聚合因子
  -> 非负权重
  -> 线性加权得分
  -> 入场与离场阈值
  -> 仓位执行状态机
```

下一代策略拟将归一化纳入因子定义，使策略计分架构压缩为“因子（含归一化）-> 有符号权重 -> 固定计分公式 -> 阈值”。本轮不实现该架构，只诊断当前冠军，避免先修改研究对象再做归因。

## 2. 数据与窗口

- 仅允许加载2020—2025年度文件；数据加载器必须在打开文件前排除2026；
- 2020年只作上市初期预热、因果计算和因子覆盖检查，不参与因素正负分类；
- 2021—2025五个完整年度是主要归因窗口；
- 2021H1至2025H2十个半年窗口是稳定性诊断窗口；
- 年度窗口决定正式分类，半年窗口用于识别单笔交易主导和年度内部反转；
- 所有窗口使用与冠军回测一致的行情、后复权方式、费用和下一交易日开盘执行模型。

## 3. 固定冠军参数

- 聚合因子权重：`[0.3, 0.3, 0.4]`；
- 入场阈值：`0.15`；
- 离场阈值：`0.0`；
- 入场确认：1个交易日；
- 最短持仓：3个交易日；
- 离场确认：1个交易日；
- 入场门控：`none`。

## 4. 归因对象

按以下层次归因：

1. `structure`、`trend`、`volume_position`三个聚合因子；
2. 当前注册的12个底层CZSC信号；
3. 底层信号中达到最小样本要求的具体分类状态及其现有语义映射；
4. 三个聚合因子的当前权重；
5. 入场阈值与离场阈值；
6. 入场确认、离场确认和最短持仓规则；
7. 聚合因子之间的交互贡献与线性计分结构限制。

未知分类状态继续保留出现次数和分布，但由于冠军当前将其映射为零，只能归为“未建模状态”，不能伪造反事实贡献。

## 5. 反事实定义

所有反事实只改变一个预注册对象，其他输入、费用、执行规则和窗口保持一致。

### 5.1 聚合因子

计算三个聚合因子的全部 `2^3 = 8` 个联盟。未加入联盟的因子贡献置零，保留原权重、计分公式、阈值和状态机。对策略收益率和夏普率分别计算精确Shapley值及两两Shapley交互指数。全空联盟始终持有现金，其收益率和夏普率在归因计算中均按零处理，避免零波动序列产生未定义夏普率。

### 5.2 底层信号与分类状态

对每个底层信号执行两种预注册反事实：

1. 贡献置零：目标信号的映射值改为零，聚合分母不变，用于衡量它在当前映射和聚合架构中的边际影响；
2. 删除重算：删除目标信号后重新计算所属聚合因子，用于识别平均聚合造成的稀释或放大。

对具体分类状态，只在该状态出现时将其映射贡献置零。状态至少需要在三个年度中各出现5个交易日，且全样本累计不少于20个交易日；否则分类为“样本不足”。

### 5.3 权重

每次只改变一个聚合因子权重 `+0.05` 或 `-0.05`，另外两个权重各反向补偿 `0.025`，保持权重非负且总和为1。权重敏感性只用于判断局部方向，不用于选出新权重。

### 5.4 阈值

- 入场阈值：`0.10、0.15、0.20`；
- 离场阈值：`-0.05、0.00、0.05`。

两类阈值分别单独变化，不做笛卡尔积搜索。

### 5.5 仓位状态机

- 入场确认：`1、2`个交易日；
- 最短持仓：`2、3、4`个交易日；
- 离场确认：`1、2`个交易日。

三个规则族分别单独变化，不组合搜索。

## 6. 指标与分类

主要指标只有策略收益率和夏普率。最大回撤、换手、持仓比例、交易次数、最大有利波动和最大不利波动只用于解释，不改变分类。

对“移除或减弱目标因素”的反事实，定义：

- `return_delta = counterfactual_return - champion_return`；
- `sharpe_delta = counterfactual_sharpe - champion_sharpe`。

材料性阈值为收益率 `0.001`（0.1个百分点）和夏普率 `0.02`。

- 稳定负向：至少4/5年度同时满足 `return_delta > 0.001` 且 `sharpe_delta > 0.02`，并且改善不受单一持仓差异区间主导；
- 稳定正向：至少4/5年度中，移除后同时满足 `return_delta < -0.001` 且 `sharpe_delta < -0.02`；
- 收益正向、风险负向：年度结果稳定表现为移除后收益下降而夏普上升；
- 风险正向、收益负向：年度结果稳定表现为移除后收益上升而夏普下降；
- 状态依赖：不同年度的材料性方向相反，且不满足稳定正向或稳定负向；
- 冗余：至少4/5年度的两个增量都未超过材料性阈值；
- 交互型：单项贡献不稳定，但联盟归因显示其与其他因子的交互具有稳定材料性；
- 样本不足：未达到状态出现次数要求；
- 未建模状态：冠军映射为零，无法通过置零构造有效反事实。

权重、阈值和状态机使用相同材料性阈值与4/5年度稳定性要求，但结论表述为“局部改善方向”，不能直接称为新最优参数。

“单一持仓差异区间主导”使用固定机器规则判定：将冠军与反事实仓位不同的连续交易日划分为独立区间，按每日策略收益差计算每个区间对全年收益差的贡献；若最大区间的绝对贡献超过全部区间绝对贡献之和的50%，则标记为主导。被标记对象可以保留年度方向证据，但不能分类为稳定正向或稳定负向。

## 7. 防止强行选优

- 本轮不计算候选PASS；
- 不按综合分数强制选出“最佳负向因素”；
- 只有满足稳定负向定义的对象才能进入下一轮优化候选清单；
- 若存在多个稳定负向因素，按最差年度收益改善、最差年度夏普改善、年度一致性、复杂度依次排序；
- 若没有稳定负向因素，停止并记录“未发现稳定负向因素”；
- 本轮不得生成 `frozen_challenger.json` 或调用2026留出集入口。

## 8. 产物

正式执行后，`artifacts/`至少包含：

- `protocol.json`：本预注册协议的机器可读版本；
- `factor_catalog.csv`：聚合因子、底层信号、分类状态和映射目录；
- `window_metrics.csv`：冠军年度与半年指标；
- `group_attribution.csv`：聚合因子联盟及Shapley归因；
- `signal_attribution.csv`：底层信号置零与删除重算结果；
- `state_attribution.csv`：具体分类状态归因；
- `weight_sensitivity.csv`；
- `threshold_sensitivity.csv`；
- `state_machine_sensitivity.csv`；
- `classification.csv`：所有对象的最终分类及证据；
- `metrics.json`：执行状态、数据边界、哈希和摘要；
- 归因热力图：仅用于浏览证据，不作为机器判定输入。

## 9. 完整性与复现

- 记录Python、CZSC、vectorbt、pandas、NumPy和Plotly版本；
- 记录冠军规则、可见行情、协议和归因产物SHA-256；
- 验证2026行情文件既未打开，也未进入数据哈希；
- 普通回测入口、冠军基线和既有实验档案不得改变；
- 正式档案必须通过实验manifest校验与最小化测试。
