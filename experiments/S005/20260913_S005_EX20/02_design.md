# S005 EX20 设计

按历史权重聚合成分股当日涨跌与个股净流入，构造价格宽度、资金流宽度、两者共同宽度，以及
等权价格宽度减权重价格宽度的“权重股拖累差”。所有阈值只使用前120个交易日，测试
Q50/Q60/Q70三个固定强度，事件间冷却3个交易日。

预注册四条长仓机制：

1. `INTERNAL_ACCUMULATION`：资金流广泛转正、价格多数上涨，但ETF当日未上涨；
2. `BROAD_PARTICIPATION_THRUST`：价格与资金共同扩散，ETF当日温和上涨；
3. `HEALTHY_MAJORITY_HEAVYWEIGHT_DRAG`：多数成分上涨而权重股拖累ETF；
4. `BROAD_WASHOUT`：价格与资金共同收缩且ETF下跌，代表广泛出清。

每条路径须达到滚动60日独立事件中位数不少于7、P10不少于3，才有资格进入固定收益检验。
本轮不能根据收益挑阈值，也不能复用S003的Q80资金流宽度入场规则。
