# 研究设计

## 身份与边界

固定`588080.SH`、`baseline_20260901`、候选143、12个因子、ER60、trend/range权重、阈值、状态机、次日开盘、费用和资金。2020只预热；2021—2025审计搜索；2026-01-01至2026-09-01只做信号错位检验。运行前后复核关键文件SHA-256。

## 四项正式分析

1. 重建EX20固定`5^4=625`候选的共同日收益矩阵，先复现候选143的EX20汇总指标。
2. 将2021—2025分成10个连续区块，枚举252个CSCV互补切分，按训练夏普选择候选并计算验证排名与PBO；使用625个trial的夏普分布计算候选143的Deflated Sharpe。
3. 展开完整四维乘数曲面，报告候选143的一步/两步邻域、距离退化和六组二维切片，不事后设“高原”门槛。
4. 对冻结2026目标仓位枚举全部非零循环位移，以夏普为主统计量计算精确经验P值；其他指标只展示。

另扫描此前46个实验形成试验账本。无法恢复的字段标为unknown；异质实验次数不得并入EX20的PBO/DSR。

完整统计定义、错误处理和产物要求以`docs/superpowers/specs/2026-09-02-baseline-robustness-validation-design.md`为准。
