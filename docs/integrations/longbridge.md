> 的历史记录，不是本分支实盘验收。新版 `StrategyInstance` 尚未重新发布 S103-v1，

行情与账户核验日期：2026-09-21至2026-09-23。范围仅限美股正股；验收过程没有向真实账户
调用下单、改单或撤单接口。

## 当前落点

- DFLS `stock.ohlcv`：显式 `vendor=longbridge` 后支持日、周、30/15/5/1 分钟历史 K 线；
- DFLS `stock.unadjusted_daily`：支持 Longbridge 美股不复权日线；
- 凭据：旧式 `APP_KEY + APP_SECRET + ACCESS_TOKEN`，进程环境优先于显式 `.env`；
- 原 Tushare 默认路径、A 股数据准备流程和 Futu 模拟盘均未改变；
- 当前分支包含只读行情，以及隔离的`longbridge_live_us`账户观察、`SHADOW_ONLY`影子账本、
  受门禁约束的订单提交、恢复对账和受限撤单。`futu_simulate_us`已按新版 PTE 接口迁入并通过
  离线合约测试，但尚未用本分支做 OpenD 端到端验收；旧分支模拟状态不能冒充新版验收。
- 只读适配器始终不暴露写方法；写入适配器位于独立模块。当前明确禁止改单，因为SDK改单
  调用没有本项目能够验证的请求幂等键。

| 检查 | 结果 |
|---|---|
| OpenAPI 美股权限 | US LV1 已开通 |
| `AAPL.US` 30 分钟线 | 可直接读取，OHLCV 与成交额字段齐全 |
| 2024-01-02 至 2024-01-03 | 26 根，常规时段每天 13 根 |
| 规范化时间 | `America/New_York` 收盘时刻，10:00 至 16:00 |
| 超过单次上限 | 2024-01-02 至 2024-05-01 返回 1,092 根、2 次请求，无重复且有序 |

| 账户分钟线下限 | API 错误码 301600 明确返回 `2023-09-01` |
| 美股期权 | 未开通；本项目不使用 |
| 账户余额/持仓接口 | 旧式凭据只读调用成功，存在 USD 现金明细与证券账户通道 |

Longbridge 官方历史 K 线页列出的美股分钟线市场范围是 2003-09 至今，同时说明单次最多
1,000 根、每 30 秒最多 60 次、每月按账户等级统计不同标的数量。实际账户请求 2003 年
分钟线时，服务端返回的账户权益下限是 2023-09-01；生产判断必须以接口返回为准，不能把
市场最早范围当成账户保证。

## 口径与安全约束

Python SDK 5.1.0 将 K 线 Unix 时间戳转换成运行机器本地时间后丢弃 `tzinfo`。适配器通过
本机历史时区规则恢复绝对时刻，再转换到美东时间；分钟柱从供应商开盘时间改写为平台的
已完成柱收盘时间。长历史使用不重叠日期块，并以 0.55 秒最小请求间隔保守遵守限频。
盘前盘后的日期块比常规时段更小，确保不超过单次 1,000 根。夜盘在本适配器中显式关闭；
完整夜盘加日间的 1 分钟单日数据可能超过按日期接口上限，必须等偏移分页单独验收后再开放。

完整区间扫描发现 9,890 根 AAPL 30 分钟柱中有一根供应商原始 OHLC 不满足包络关系：
2026-05-27 第一根柱的未复权 `Open=308.330`、`Low=308.380`，前复权返回也存在同一关系。
适配器采用与平台既有首柱规范化一致的最小处理：只扩大 `High/Low` 以包含 `Open/Close`，
并在元数据记录修正次数与修正前原值摘要哈希；不会以日线回填分钟线。

完整区间发布后时间戳唯一且单调递增；757 个完整交易日各 13 根，7 个提前收市日各 7 根。
该次前复权发布内容 SHA-256 为
`18babf56273ec69e5d5cc5cc19d53620c49498968d169981bdd33ee3151ad262`。

实测 Longbridge 分钟线聚合结果与其日线存在成交口径差异：AAPL 2024-01-02 常规时段
30 分钟成交量合计 14,535,048，而日线为 82,488,674；2024-01-03 分别为 9,993,263 与
58,414,460。适配器不猜测该跨周期差异的原因，也不用日线篡改分钟值。研究必须固定数据
身份，不得混合日线与分钟线后宣称二者已完成量价对账。

新版 PTE 有隔离的`futu_simulate_us`渠道。独立 LEG 以 Longbridge
的 USD 可用现金、正股持仓、订单与成交为事实来源，并负责整股、订单幂等、恢复对账、
风险上限、熔断和人工启用门禁。

实盘订单写适配器现支持显式 `outside_rth=RTH_ONLY / ANY_TIME / OVERNIGHT`，对应常规、
盘前/盘后及夜盘。盘前/盘后/夜盘只接受限价单；美东常规 09:30–16:00，`ANY_TIME`
允许 04:00–20:00，夜盘 20:00–次日 03:50 且归属次一交易日。券商仍会按账户权限、
证券是否有 24H 标识、假日及价格等条件独立拒单；代码支持提交不等于保证成交。
新版 SRT/PTE 共用订单合约尚未携带 `outside_rth`，因此当前策略信号仍默认
`RTH_ONLY`，不能宣称已经具备四时段策略自动交易。扩展共用合约和相应模拟/研究验收前，
不得靠更改环境变量或后台服务时钟绕过这层边界。

只读验收已证明当前旧式凭据可以访问Longbridge账户余额、股票持仓、当日订单和成交接口。
独立 LEG 保存这些事实以及近30日恢复窗口。实盘执行器已
具备确定性客户端请求ID、持久化券商备注、重启恢复、现金与持仓约束、活动订单排他、限时授权、
人工停用和本部署订单撤单。

部署登记时保持`DISARMED`；S103-v1旧制品当前是`PAPER_READY`而非`LIVE_READY`，
且不兼容新版 SRT。环境变量不能改变这些状态。本次没有发送真实试单；何时把新版策略升级
为`LIVE_READY`以及何时设置额度、
完成限时授权，仍由用户单独决定。


大白话：现在可以在新版平台拉美股训练数据、读取长桥账户并验证实盘网关的安全门禁；
旧 S103 守护脚本不能直接在新版分支启动。必须先完成冻结策略的新版部署迁移及 OpenD
端到端模拟通道验收，才谈得上重新部署；这不需要修改原始冻结文件。

仓位边界：既有 S103-v1 的目标只有 0/1，`allocation_fraction=0.98`只规定每次入场
最多动用的现金比例，并不等于持仓过程中可在 30% 与 70% 之间任意调仓。新版平台原有
S003 的 50% 核心仓位加 50% 事件轮换机制保持不变；本次接入保留了美股整股数量与
入场资金比例，但没有悄悄扩展冻结规则为任意目标仓位。
