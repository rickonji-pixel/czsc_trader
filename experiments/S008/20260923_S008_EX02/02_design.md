# S008 EX02 实验设计

## 固定边界

- 前序实验：`20260920_S008_EX01`，裁决为`FAIL_DATA_GATE`；
- 标的：518880.SH，ETF；
- 全量数据准备区间：2013-07-29至2026-09-18；
- 开发池：2013-07-29至2024-12-31；
- 封存验证池：2025-01-01至2026-09-18；
- 封存验证池本轮只做数据完整性与身份校验，不计算收益、不观察价格路径、不参与规则选择；
- 数据源：Tushare；历史修复由DFLS登记的`TUSHARE_518880_V1`负责，实验不得手工改写数据。

## 数据门

1. 使用正式`data prepare`入口生成后复权日线、30分钟线、周线和不复权执行日线；
2. 使用正式`data validate`入口完成频率完整性与日周对账；
3. 验证清单内文件哈希、日期唯一性、OHLC关系、成交量和成交额非负；
4. 验证后复权日线与执行日线交易日完全一致，开发池和封存验证池均非空；
5. 固化数据清单、校验报告、修复记录和命令结果，并在通过时登记`research/S008/materials.json`。

裁决只有两种：全部通过则`PASS_DATA_GATE`；任一检查失败则`FAIL_DATA_GATE`并停止后续机制研究。
本实验不计算收益、回撤、相关性或信号，不搜索参数，不创建候选，不修改平台模块、冻结策略或PTE。
