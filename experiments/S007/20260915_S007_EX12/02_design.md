# S007 EX12 设计

固定EX11以参数几何中心选出的试验，不再按收益换配置。审计包含：

1. 单边5、10、15bp费率压力，最高压力下仍须满足年化24.078%、最大回撤20%及频率门槛。
2. 每次删除一个因子、其余权重按比例归一，沿用原入退场分位数并从发现期重新计算阈值；若
   简化结构同时不降低年化、不恶化回撤并满足频率门，则原七因子结构不得进入候选。
3. 六个自然年逐年与BuyHold比较，要求每年相对收益均为正。
4. 对策略与BuyHold的配对日对数超额收益做20交易日圆形区块Bootstrap，5000次，要求正年化
   超额概率不少于90%。

这些门槛在读取本轮新增结果前固化。通过只表示可以进入候选形成与SE体检，不等于冻结。
