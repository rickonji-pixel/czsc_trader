# S007 EX18 设计

- 固定使用EX17的两个锚点和逐笔交易结果，不重新选择参数；
- 标签为现有退出规则下的持有期限：1—3日=`SHORT`，4日以上=`DURABLE`；
- 仅使用信号生成日及更早数据，预注册8个事前特征：越线幅度、1日/3日分数变化、最近3日
  位于退出阈值之上的天数、角色同向数、连续2日同向角色数、最大角色贡献占比、确认角色贡献；
- 每个锚点分别计算AUC、上下三分位持续率差、5000次标签置换p值和逐年留一方向一致性；
- 发现支持要求：两个锚点方向一致，方向化AUC均不低于0.60，各自BH-FDR q值不高于0.10，
  且逐年留一方向一致率均不低于80%；
- 持有期限由当前退出规则共同决定，因此结果只能支持后续原型研究，不能证明独立Alpha；
- 不形成门控规则、不搜索阈值、不创建候选、不修改SM/PTE。
