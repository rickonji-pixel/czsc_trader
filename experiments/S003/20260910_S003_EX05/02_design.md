# S003 EX05 设计

## 预注册机制

从EX04的182个密度合格状态中，仅保留金融语义明确、事件行为哈希不同的7个做多假设：

1. `M01`：近10根15分钟K线上涨动量延续；
2. `M02`：近10根15分钟K线下跌后的短期反转；
3. `M03`：15分钟弱底分型后的结构修复；
4. `M04`：RBreaker给出做多区域后的延续或反转做多；
5. `M05`：CCI进入开多决策区后的超卖修复；
6. `M06`：当前收盘高于10根前收盘的价格动量延续；
7. `M07`：MACD方向向上后的动量延续。

信号函数、主状态、EX04状态ID和行为哈希全部写入`protocol.json`。没有读取收益后再替换信号的空间。

## 因果执行

- 信号：每根已完成15分钟K线；同一状态同一日只取首次切入；
- 入场：严格晚于信号收线的下一根5分钟K线开盘价；
- 退出：入场后的下一交易日，固定比较`09:45`、`10:30`、`11:30`、`15:00`四个退出时点；
- 账户：每个机制独立按单账户顺序执行，持仓期间忽略新信号，不排队；退出完成后的新信号方可再次入场；
- 成本：基准单边1.2bp，压力单边6bp，分别约等于往返2.4bp和12bp；
- T+1：退出交易日必须晚于实际入场交易日。

四个退出时点在读取收益前整体冻结。它们用于判断隔夜修复在早盘、上午或全天哪个区间存在，不能在本轮直接选出正式策略参数。

## 证据速度与方向证据

按完整交易日历统计滚动30交易日闭合交易数。中位数不低于18且P10不低于12才通过硬性证据速度门槛。

每个机制×退出时点采用以下预注册证据标签：

- `EVIDENCE_RATE_FAIL`：闭合交易速度不达标；
- `DIRECTION_FAIL`：速度达标，但压力成本后平均收益不为正或盈亏比不大于1；
- `SUPPORTED`：速度达标、方向通过、相同时刻与regime匹配的随机收益分位不低于90%，且至少4个年度平均收益为正；
- `MIXED`：速度和方向通过，但随机对照或跨年一致性不足。

随机对照固定2,000次、随机种子20260910，只匹配信号时刻与开盘前regime。该对照用于判断信号是否超越同环境随机入场，不声称解决全部相关性或多重试验问题。

## 边界

本轮不创建S003候选，不以最高收益挑选退出时点，不引入日线regime硬过滤。只有同一机制在相邻退出时点呈现一致方向，且存在满足证据速度的执行口径，才值得进入下一轮原型规则研究。
