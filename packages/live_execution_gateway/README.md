# Live Execution Gateway

本包是Longbridge美股正股实盘的独立执行宿主。它复用冻结SRT产生决策，但不复用PTE账户、
资金或订单；Longbridge账户是实盘现金、持仓、订单与成交的事实来源。

## 默认状态与三重门禁

登记部署不会开实盘。真实订单必须同时满足：

1. 策略生命周期已经由治理流程变为`LIVE_READY`，冻结版本哈希与部署完全一致；
2. 操作人显式修改风险额度，部署仍为`DISARMED`且不存在待提交或未决订单；
3. 操作人获取五分钟有效的一次性挑战短语，并用操作人、原因和1至24小时有效期完成授权。

环境变量不能开启实盘。授权到期、人工停用、策略身份变化、订单对账冲突、下单或撤单结果
不确定，都会拒绝新订单；不会偷偷重试，也不会因为停用而擅自撤销券商已有订单。

大白话：先具备读账户、记录计划、对账和受控下单的基础设施；策略版本还得按新版 SRT
重新形成可部署发布包并通过 `LIVE_READY`，之后你亲手设置额度、限时授权，才可能发真实单。

当前旧版 S103-v1 制品使用已废弃的 `runner/publisher` 协议，不能直接在新版
`StrategyInstance` 加载。此集成分支没有重写该冻结制品，也没有把它伪装成新版发布包。
旧 S103 部署不得在本分支执行 `arm`。

## 执行与恢复边界

- 固定渠道`longbridge_live_us`，只接受`.US`正股、整股、`DAY`订单；
- 订单适配器支持 `RTH_ONLY`、`ANY_TIME`、`OVERNIGHT`。盘前、盘后和夜盘只能用限价单；
  当前新版 SRT 订单计划尚未传递非默认时段，因此策略自动单仍是常规时段；
- 每项意图先写入SQLite，再以确定性`client_request_id`和`LBI-*`券商备注提交；
- 提交前持久化为`SUBMITTING`。进程在任意位置退出后，先读取近30日订单和成交，按备注恢复；
- Longbridge的客户端请求键只有有限缓存窗口。任何网络异常都按“订单可能已经送达”处理，
  禁止自动重试；十分钟内仍无法在券商侧确认时阻塞部署；
- 同一标的已有活动订单时不提交新单，避免持仓尚未更新时重复买卖；
- 买单只使用USD可用现金，不使用融资购买力，并保留配置的现金缓冲；
- 撤单只允许作用于本部署已经绑定的订单，并需要固定确认短语；
- 不支持改单。Longbridge改单接口没有本项目可验证的请求幂等键，安全做法是显式撤单、等待
  对账完成，再由新的SRT决策产生新订单；
- 可由 macOS LaunchAgent 负责进程退出后的自动拉起。Mac关机、睡眠或断网时无法连接券商；
  恢复后先对账再继续，绝不伪造错过的成交；旧 S103 LaunchAgent 脚本不兼容新版平台，
  本分支不安装或启动它；
- 常驻宿主每60秒对账；原始账户快照最多保留最近20,000份，订单与成交表不随快照轮换删除。

`max_order_notional`以SRT执行参考价做提交前估算。市场单的最终成交价由券商和市场决定，
因此该值不是成交金额的绝对价格保证；现金不足仍由本地可用现金检查和券商风控共同拒绝。

## 此分支可用的只读验收

```bash
./.venv/bin/python -m pip install -e './packages/live_execution_gateway[test]'
./.venv/bin/longbridge-live preflight --env-file .env --symbol MU.US
```

`preflight`只调用长桥只读接口。当前集成分支的实盘资格与运行时迁移尚未完成，请勿安装
旧版 S103 守护脚本；更不能以改写旧冻结文件的方式绕过发布治理。
