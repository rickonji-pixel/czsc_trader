# v0.4.0：三节点治理与统一策略执行

验收日期：2026-09-19。版本以附注Tag保存，覆盖已验收实现及配套文档。

## 交付内容

- **TDR三节点治理**：人工确认研究立项、候选送审、正式冻结。一份SGC凭据沿链路追加
  立项、送审、裁决、批准和冻结五类印章。研究意图允许修订，最终评价目标在送审时锁定。
- **候选与冻结共用SRT**：送审前完成候选实现、参数和源码绑定；冻结沿用同一实现与参数，
  校验数据、决策、执行及监测契约，转换生命周期身份。候选不伪装成未来冻结版本。
- **TXE统一历史执行**：`HistoricalExecutor`实现SRT执行渠道，研究搜索、候选及冻结策略
  回测、正式审核共用订单、成交、费用、现金与持仓口径。移除`BacktestChannel`包装层。
- **独立复算及证据封存**：TDR校验研究池数据源，通过SRT与DFLS离线发布到
  `data/review/<credential_id>/<submission_hash>/`，独立复核主张并组织完整体检。
  缺失输入、证据变化或身份不一致明确失败；重复评估和正式冻结仍检查封存证据。

## 兼容与运行边界

- 保留S001-v1/v2、S002-v1、S003-v1、S007-v1的正式身份与执行行为，以
  `LEGACY_GOVERNANCE_ACCEPTED`记录历史治理迁移。
- 历史实验保留供人工查看和档案校验，不承诺旧研究脚本重放兼容。当前候选评估与回测
  退出旧规则解析链路；只读历史基线查询仍保留。
- Git克隆提供源码和公开文档；行情、审核快照、实验产物和运行状态属于本地资产，需另行准备。
- PTE继续以Futu回报作为账户事实。Tag不触发部署、服务重启或交易，本次验收未改动正式PTE状态。
