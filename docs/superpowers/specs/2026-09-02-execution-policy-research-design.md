# 588080低关注度执行规则研究设计

日期：2026-09-02  
研究分支：`codex/0902-execution-policy-research`  
预计实验：`0902_EX02`

## 1. 目标

为活动信号基线`baseline_20260901`增加一套独立、可冻结、可回测、可审计的执行规则。执行规则服务于每天查看一次账户、无法固定时段盯盘的人工交易方式。

活动基线继续负责生成T日收盘后的目标仓位`0/1`。执行规则负责在T+1生成可直接提交的委托参数，并持续维护待入场、已持仓、待离场、空仓四种实际执行状态。

本轮不修改活动基线的因子、权重、阈值、regime分类和目标仓位。实验完成后输出晋升建议，活动执行规则的正式晋升由用户确认。

## 2. 已确认约束

- 标的：`588080.SH`。
- 信号版本：`baseline_20260901`，SHA-256以活动注册表解析结果为准。
- 用户每天至少查看一次建议和券商账户，操作时间不固定。
- 入场允许因价格过高而放弃；离场以完成卖出为优先。
- 普通限价单只能表达单侧价格约束，因此正式入场参数为“最高可接受买入价”。异常低开价只作风险提示。
- 未收到明确成交回报时，实际账户继续按未成交处理。
- 实际仓位与目标仓位独立记录。
- 用户当前规模为50,000份；流动性诊断按该数量展示，不将历史成交量等同于确定成交。
- 基金价格最小变动单位按0.001元处理；理论最高买入价向下取整到价格档位。

## 3. 券商委托映射

招商证券界面提供限价委托、对手方最优价格、本方最优价格、五档即成剩撤、五档即成转限价和盘后固定价格。

正式规则采用：

- 入场主方式：限价委托；
- 离场预挂主方式：限价委托，价格以当日合法价格下限为保护边界；
- 连续竞价期间的离场补救：五档即成转限价，并设置卖出保护限价；
- 盘后固定价格：2026-07-06以后可用的补充通道，只作操作说明，不进入2020—2025历史绩效比较。

五档盘口深度无法由30分钟K线精确重建，因此市价类委托不生成虚构的精确历史成交价。

## 5. 状态机

| 目标仓位 | 实际仓位 | 状态 | 下一步 |
|---:|---:|---|---|
| 0 | 0 | 空仓 | 等待新入场信号 |
| 1 | 0 | 待入场 | 每个交易日生成一张当日有效限价买单 |
| 1 | 1 | 已持仓 | 继续持有 |
| 0 | 1 | 待离场 | 每个交易日生成离场委托，直至明确成交 |

入场订单当日未成交后自动失效。下一交易日只要目标仓位仍为1，就使用最新完整收盘数据生成新价格上限。目标仓位回到0时，待入场状态结束。

离场订单当日未成交时，实际仓位保持1，待离场状态延续。研究账本记录延迟天数。

## 6. 候选价格公式

### 6.1 固定比例族

```text
raw_cap = close_T * (1 + premium)
buy_limit = floor_to_tick(raw_cap, 0.001)
```

候选`premium`覆盖`-2.00%`至`+5.00%`，步长`0.25%`。

### 6.2 ATR自适应族

```text
ATR20_T = 20日True Range均值，仅使用T日及以前数据
raw_cap = close_T + multiplier * ATR20_T
buy_limit = floor_to_tick(raw_cap, 0.001)
```

候选`multiplier`覆盖`-0.50`至`2.00`，步长`0.125`。

ATR不足20日的日期不参与ATR候选的正式成交统计；固定比例族仍可运行。

### 6.3 异常低开警戒

警戒价作为报告字段，不改变限价单成交逻辑。候选冻结后，使用研究集入场信号次日开盘收益的下侧5%分位数定义：

```text
warning_price = floor_to_tick(close_T * (1 + frozen_gap_q05), 0.001)
```

## 7. 历史成交模型

入场限价单在T日收盘后生成并在T+1开盘前进入待执行状态：

```text
if open_T1 <= buy_limit:
    fill at open_T1
elif first_30m_bar_with_low_at_or_below_limit exists:
    fill at buy_limit at that bar timestamp
else:
    unfilled for T+1
```

当日最低价只用于初筛。正式成交时间由30分钟K线的首个触价区间确定。触价成交价采用限价，形成保守估计。

离场主模型沿用下一交易日首次可成交价格。遇到停牌、缺失行情或无法证明可成交的极端价格状态时，订单保持未成交并延续。市价类补救单只记录操作路径，不生成盘口级回测价格。

手续费统一使用活动基线的`0.0005`。

## 8. 候选选择协议

一次目标仓位`0 -> 1 -> 0`定义为一个入场周期。

硬要求：

- 研究集T+1当日入场周期成交率至少为90%；
- 信号日期严格早于委托日期和成交日期；
- 计算过程中无2026数据访问；
- 实际仓位只能由模拟成交改变。

合格候选按以下顺序确定唯一优胜者：

1. 入场日价格上限溢价的95%分位数最低；
2. 平均价格上限溢价最低；
3. 研究集最差有效年度卡玛比率最高；
4. 研究集最差有效年度最大回撤绝对值最低；
5. 固定比例族优先；
6. 参数数值较小者优先。

“有效年度”指至少包含一个完整入场周期的年度。收益率、夏普率和盈亏比作为客观结果展示，不参与前两级执行质量选择。

## 9. 比较指标

当前无条件T+1开盘成交作为对照。研究集整体、逐年和2026测试集统一输出：

- T+1成交率、两日累计成交率、最终成交率；
- 平均和最长等待天数；
- 完全错过周期数；
- 错过后上涨幅度与错过收益；
- 相对T日收盘溢价、相对T+1开盘价格改善、最差成交溢价；
- 收益率、最大回撤、卡玛比率、盈亏比、夏普率；
- 当日离场率、延迟离场次数和最长延迟；
- 50,000份占首个触价30分钟成交量的比例。

流动性比例只作诊断，不形成额外PASS门槛。

## 11. 错误处理与审计

- 活动基线版本或哈希变化时停止；
- 行情清单或数据校验失败时停止；
- 2026在规则冻结前被访问时停止；
- 30分钟数据与日线日期无法对齐时停止；
- 候选不足90%成交服务水平时归档为`FAIL`，保留完整证据；
- 运行异常时归档为`ERROR`，记录异常类型和信息；
- 运行前后校验活动基线、行情文件和历史实验关键哈希不变。
