# ETF 原始历史数据

此目录保存回测使用的原始 CSV；读取阶段禁止补值、复权或改写。脚本读取时可将 `date` / `volume` 映射为内部使用的 `trade_date` / `vol`。

可通过 `bt_engine/src/bt_engine.py fetch-etf-history` 从 Tushare 获取 A 股 ETF 周线、日线和 30 分钟线。默认模式按年份增量合并 `{代码}_{weekly|daily|30m}_{年份}.csv`。使用 `--rebuild` 时，`bt_engine` 只从适配器获取日线和 30 分钟线，在引擎内跨年度聚合周线，完成对账后一次性批量原子替换全部请求年度文件；任何替换失败都会恢复原文件。
